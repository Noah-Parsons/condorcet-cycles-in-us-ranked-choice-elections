# P65 — Condorcet cycles in US ranked-choice elections

**Field:** Economics  
**Size:** Medium (one project season)  
**Time:** 6 weeks

## Question
In public ballot data from US ranked-choice elections (Alaska, Maine, New York City, others), how often is there no Condorcet winner, and how often does the RCV winner differ from it?

## Why it matters
RCV is spreading across the US, and the real frequency of these failures is contested.

## Builds on
R/Python data skills

## Method
1. Collect the cast-vote records
2. Compute pairwise matrices, Condorcet winners and cycles
3. Report rates with uncertainty; publish the code

## Deliverable
Report + dataset.

## Risks
Some studies exist; extend to newer elections.

## Before you start: novelty check
Search Google Scholar / arXiv / GitHub for: _Condorcet winner frequency ranked choice voting cast vote records_. If the question is already answered, narrow it or pick another project.
